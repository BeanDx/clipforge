## What's new

### 👤 New Profile tab
A CS2 profile page for you or any player: paste a SteamID, a Steam or FACEIT link, or a FACEIT nickname.
- **Steam**: avatar, online status, VAC and trade bans, account age. Works without any key.
- **FACEIT** (with a free Data API key in Settings): level ring with Elo and how much is left to the next level, matches, win rate with the last results, K/D, headshot rate, ADR and best streak.
- **Form**: K/D for each of the last 30 matches, wins and losses in different colours.
- **Maps**: win rate and K/D per map, the best one is marked.
- **Recent matches**: click one to open its FACEIT room.
- **From your games**: hours in CS2, matches recorded by clipforge, aces and 4Ks, favourite weapons.

### ⬇ FACEIT demos from match history
- FACEIT matches in **Home → Match history** get a **download demo** button. It opens the match room, you click *Watch demo*, and clipforge picks the file up from Downloads, unpacks the `.dem.zst` / `.dem.gz` into CS2 replays and links it to the match.
- FACEIT matches that weren't recorded while you played show up in the history too, with score and result.

### 🔄 Automatic updates
- clipforge checks for new versions on start and every 6 hours. When one is out, you see what changed and update in one click: download with progress, signature check, install and restart.
- **Settings → About** has a **check for updates** button.
- This is the first version with updates: install it by hand once, the next ones arrive by themselves.

### Also
- If Steam rate-limits requests (error 429), the profile shows saved data, and your own profile is built from local Steam files.
- Fixed: importing failed with "Access denied" when Downloads had a folder named like a demo.

## По-русски
- **Новая вкладка «Профиль»**: профиль CS2 любого игрока по SteamID, ссылке на Steam или FACEIT, нику FACEIT.
  - Steam: аватар, статус, баны, возраст аккаунта, без всяких ключей;
  - FACEIT: уровень и эло, винрейт, K/D, ADR, форма за 30 матчей, статистика по картам, последние матчи;
  - твоя статистика из игры: часы, эйсы, любимое оружие.
- **Демки FACEIT из «Истории игр»**: кнопка «скачать демку» открывает матч на FACEIT, а скачанный файл clipforge сам забирает из «Загрузок», распаковывает и привязывает к матчу.
- **Автообновление**: программа сама находит новую версию, показывает список изменений и обновляется в один клик. Эту версию нужно поставить вручную один раз, дальше всё придёт само.
- Если Steam временно ограничил запросы (ошибка 429), профиль показывает сохранённые данные.
