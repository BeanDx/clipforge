## What's new

### 🎬 Edit mode and the Cinematic preset
- The **Demo** tab now asks what you're making: **Clips** (highlights from one demo) or **Edit** (a beat-synced edit from several demos).
- New edit preset **Cinematic** next to Night Edit: the game is recorded through ReShade with depth-based effects: soft contact shadows, coloured light bounced off walls, reflections on floors and glass, bloom, a film grade and an optional 2.39:1 letterbox. Text can be one word per beat or off.
- The same look is available for ordinary clips: **Effects → Cinematic look**.
- ReShade downloads once on the first build (~10 MB). CS2's MSAA is turned off while recording and restored afterwards, even if clipforge crashed mid-recording.

### ✂️ Cut the running between kills
- **Effects → Cut the running between kills**: when a multi-kill moment has a long run across the map between kills, the middle is cut out. You get one clip with a cut, and HUD, damage, slow-mo and replays still line up.

### 🐔 Broken FACEIT demos are fixed automatically
- Some FACEIT demos crash CS2 right after playdemo (a pet chicken lands in the first tick). clipforge now repairs them in place when you open or download them and tells you what it fixed. Gameplay is unchanged.

### Also
- **Voice chat during replay**: choose whether voice is heard on the victim's-view replay (off by default, game sound only).
- If CS2 closes mid-recording, clipforge says which clip was cut short and which weren't recorded, so you can re-render just those.
- The free-space check is much more accurate: it counts only the clips on disk at the same time and the space the previous render's raw footage will free.
- A just-for-fun **counter** at the bottom of Settings shows how many clips and edits all clipforge users have rendered. After each finished render clipforge sends one empty request to abacus.jasoncameron.dev, with no file names and no demo data.

## Download
**`clipforge_0.9.0_x64-setup.exe`** for Windows 10/11 (the `.msi` does the same). If you have 0.8.0, it updates by itself.

## По-русски
- **Режим «Эдит» и пресет Cinematic**: на вкладке «Демо» выбираешь «Клипы» или «Эдит». Новый пресет Cinematic записывает игру через ReShade: мягкие тени по углам, цветной отражённый свет, отражения на полу и стёклах, свечение, кино-цвет и кинорамка. Для обычных клипов то же самое есть в «Эффектах» как «Кино-графика». ReShade скачивается один раз (~10 МБ).
- **Вырезать поиск между киллами**: если между киллами одного момента долго бегаешь по карте, середина вырезается, получается один клип со склейкой.
- **Сломанные демки FACEIT** (курица-питомец в первом тике крашила CS2) теперь чинятся автоматически, геймплей не меняется.
- Голосовой чат на повторе можно включить или выключить. Если CS2 закрылась посреди записи, clipforge говорит, какие клипы перезаписать. Проверка свободного места стала точнее. Внизу «Настроек» появился шуточный общий счётчик рендеров.
