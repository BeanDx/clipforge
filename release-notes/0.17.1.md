## What's new

### 🎨 New look by default
- **Lumen** is now the default theme for everyone: menu on the left with icons, soft cards, clips built step by step. The old **Tactical** look is still in **Settings → Appearance**.
- New app icon.

### ⚙️ Settings menu
- Opening **Settings** shows its sections right under it in the left menu. Click one to scroll smoothly to it, and a line fills in as you scroll so you always see where you are.

### Changes
- The **Queue** tab is gone from the menu for now.
